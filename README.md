# Стриж — ERID маркер

Готовое локальное приложение для маркировки видео. Здесь публикуются сборки; репозиторий разработки остаётся приватным.

## Скачать

- [Windows](https://github.com/LUCIUS-5158/strizh-releases/releases/latest/download/strizh-windows.zip)
- [macOS — Intel и Apple Silicon](https://github.com/LUCIUS-5158/strizh-releases/releases/latest/download/strizh-macos.zip)
- [Все выпуски](https://github.com/LUCIUS-5158/strizh-releases/releases)

Распакуйте архив целиком и запустите приложение своей системы. На Windows оставьте EXE рядом с папкой app. На Mac запускайте «Стриж — macOS.app». Приложение откроет локальную страницу в браузере. Отдельный помощник и код подключения не нужны.

Обновления проверяются при запуске и скачиваются с GitHub без входа в аккаунт. Они не прерывают текущую обработку. При отсутствии интернета используется сохранённая версия. Ручной режим доступен офлайн; таблицы и облачные файлы требуют интернета.

Пакеты обновлений проверяются по цифровой подписи и контрольной сумме. Если новая версия не запускается, приложение возвращается к предыдущей.

macOS-приложение собрано на macOS, но не нотарифицировано Apple. При первом запуске система может запросить разрешение в настройках безопасности. GitHub Actions не заменяет подпись Apple Developer ID.

Не закрывайте приложение во время обработки видео.
